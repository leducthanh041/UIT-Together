# Research and navigation refinement review — 2026-10-12

## Design read and implementation

The approved Premium Academic Editorial direction remains in force: navy/blue identity, measured rhythm, low motion, and research content as the visual focus. This pass makes four targeted refinements rather than changing the Home composition.

- Home statistics now use a pale UIT blue surface, navy figures, smaller icons and type, thin separators, and compact padding. The build still supplies `group_stats`; the markup contains no metric values.
- The Resources dropdown is removed. The main navigation directly exposes Home, Research, Member, Publications, Datasets, Conferences, and Contact. News and Tutorials remain available at their existing routes. Mobile menu behavior and EN/VI switching remain shared.
- Shared page headers use compact padding, a 34–42px responsive title, close subtitle spacing, and a subtle bottom divider. Members keeps its current search, cohort filtering, grouping, order, and anchors; only the gap below its page header is reduced.
- Four existing research directions use one Jinja partial and a shared text/media layout. Desktop allocates 45/55 to text and media; mobile places text before media. Existing copy and media sources are preserved. Images remain uncropped, carry alt text and captions; videos retain controls and existing reduced-motion handling.

Design purpose: lighter statistics preserve the Home hero's priority; direct links make destinations scannable without a dropdown; shorter page headers bring useful content into view; a repeated research composition helps compare real directions while keeping each direction as an editorial section instead of a product card.
